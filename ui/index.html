Сохраните API-ключ WikiVibe, выберите модель и настройте поддерживаемые файлы агентов. Плагин изменит эти файлы только с вашего согласия.

01

API-ключ WikiVibe

Нет аккаунта? Зарегистрироваться в WikiVibe

Ввод скрыт. После проверки плагин сохраняет ключ в зашифрованном хранилище Orca, отдельно от файлов агентов.

Сохранённый ключ не возвращается в браузер. Повторный ввод нужен только для замены ключа.

02

Модель и адрес API

Выберите модель из каталога вашего аккаунта. Эти настройки плагин использует при следующем применении к агентам.

При смене адреса заново загрузите модели, затем сохраните настройки.

Каталог возвращает выбранный API. Проверка ключа и загрузка каталога не подтверждают, что запрос к модели пройдёт или что она поддерживает протокол выбранного агента.

Проверьте и сохраните API-ключ, чтобы загрузить доступные модели.

03

Настройка агентов

Выберите агентов и посмотрите, какие файлы изменит плагин. Доступная карточка означает поддержку формата конфигурации, а не проверку установки агента или совместимости модели. Заранее никто не выбран.

API-ключ в открытом виде. Хранилище Orca зашифровано, но при применении плагин запишет ключ открытым текстом в указанные файлы агентов. Не публикуйте эти файлы и не добавляйте их в репозиторий. Резервные копии тоже могут содержать прежние ключи и другие секреты.

Предварительный просмотр

          Для восстановления нужны резервные копии плагина. Если файл изменился после применения, плагин откажется его перезаписывать. Каждый файл изменяется отдельно: общей транзакции для всех файлов нет.

          Настройки действуют для новых сессий. Перезапустите выбранный агент после применения или восстановления. Уже запущенные сессии не переключаются автоматически.

          Плагин меняет только стандартные файлы в локальном домашнем каталоге. Настройки проекта, переменные окружения, параметры запуска, управляемые настройки и профиль Orca могут переопределить их. SSH и WSL не настраиваются. JSONC, сложные YAML/TOML и закрытые форматы не изменяются.

          Удаление сохранённого ключа затрагивает только защищённое хранилище плагина в Orca. Файлы агентов и записанный в них ключ останутся на диске. Чтобы отменить изменения, используйте восстановление из резервных копий.

          Локальный сервер закрывается после четырёх минут бездействия. Orca также может остановить процесс плагина через пять минут после команды, даже если вы работаете со страницей. Если связь пропала, снова выполните «WikiVibe: Настроить». После перезагрузки вкладки панель тоже нужно открыть этой командой заново.
