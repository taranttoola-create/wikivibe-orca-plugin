    Предварительный просмотр

            Для восстановления нужны резервные копии плагина. Если файл изменился после применения, плагин откажется его перезаписывать. Каждый файл изменяется отдельно: общей транзакции для всех файлов нет.

            Настройки действуют для новых сессий. Перезапустите выбранный агент после применения или восстановления. Уже запущенные сессии не переключаются автоматически.

            Плагин меняет только стандартные файлы в локальном домашнем каталоге. Настройки проекта, переменные окружения, параметры запуска, управляемые настройки и профиль Orca могут переопределить их. SSH и WSL не настраиваются. OpenCode JSONC поддерживается; сложные YAML/TOML и закрытые форматы не изменяются.

            Удаление сохранённого ключа затрагивает только защищённое хранилище плагина в Orca. Файлы агентов и записанный в них ключ останутся на диске. Чтобы отменить изменения, используйте восстановление из резервных копий.

            Исходный код и инструкция

            Локальный сервер закрывается после четырёх минут бездействия. Orca также может остановить процесс плагина через пять минут после команды, даже если вы работаете со страницей. Если связь пропала, снова выполните «WikiVibe: Открыть защищённую настройку». После перезагрузки вкладки панель тоже нужно открыть этой командой заново.
