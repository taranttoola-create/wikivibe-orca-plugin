# История изменений

## 1.0.5

- Из текста панели убрано слово «реферальную»; адрес регистрации не менялся.
- Каталог объединяет все опубликованные модели всех групп и модели текущего ключа. Модели без доступа помечены отдельно; изображения и другие типы не скрываются.
- Поведение кнопок sidebar оставлено без изменений. Регистрация и защищённая настройка открываются командами Orca; кнопка подсказки в панели сама страницу не открывает.

## 1.0.4

- Исправлен отсутствующий импорт localhost-сервера: команда защищённой настройки в 1.0.3 завершалась ошибкой `startControlServer is not defined`.
- Удалена неработающая ссылка из sandbox-панели Orca. Вместо неё показана команда регистрации; кликабельная реферальная ссылка с понятной надписью остаётся на защищённой localhost-странице.
- Версия **1.0.4** видна в обеих панелях. Добавлены инструкции повторной установки с новым тегом и проверки фактически установленной версии; ошибка Git не считается успешным обновлением.
- Worker smoke теперь выполняет открытие настройки и регистрации, а не только удаление ключа.

## 1.0.3

- Вместо технического URL добавлена надпись **Открыть WikiVibe и зарегистрироваться**. Ссылка в боковой панели оказалась неработающей из-за политики Orca; исправлено в 1.0.4.
- Добавлена отдельная команда Orca **WikiVibe: Открыть WikiVibe и зарегистрироваться**, использующая ту же реферальную ссылку.
- Версия плагина, упаковки и инструкции обновлены до `1.0.3`.

## 1.0.2

- Добавлена нативная видимая панель `WikiVibe` в правую панель Orca. Она показывала адрес регистрации и объясняла ввод ключа и почему WikiVibe не появляется отдельным агентом.
- Manifest теперь вносит `contributes.panels`; sandboxed panel bridge проверен на Orca 1.4.223. Панель не получает доступ к secrets и не просит вводить ключ в небезопасный канал.
- Основная настройка теперь называется `WikiVibe: Открыть защищённую настройку`; README и сообщения обновлены с учётом видимой панели и версии 1.0.2.

## 1.0.1

- В версии 1.0.1 были приведены ссылки на репозиторий и исходники к `https://github.com/taranttoola-create/wikivibe-orca-plugin`. Основной адрес установки был закреплён за тегом версии `v1.0.1`; эта запись сохранена для истории.
- README 1.0.1 описывал установку через Git URL и локальную папку, подключение, нативные пути и протоколы агентов, риски хранения ключей, восстановление и разбор ошибок.
- Название WikiVibe Gateway и описания плагина были согласованы; доступность адаптера не выдавалась за обнаружение CLI, а каталог моделей — за подтверждение успешного запроса.
- Удаление ключа было названо по фактическому действию: команда удаляет ключ из хранилища Orca, но не меняет конфигурации и не отключает сессии агентов.
- Инструкции упаковки версии 1.0.1 использовали тег или полный 40-символьный SHA для Git URL; сокращённый SHA не рекомендовался.

## 1.0.0

- Создан самостоятельный плагин `wikivibe.gateway` для Orca plugin API 1. Поддержана обычная установка из локальной папки или Git-источника; отдельный helper не нужен.
- Добавлены регистрация по партнёрской ссылке, разрешённые адреса API/VAPI, проверка каталога до сохранения ключа в зашифрованном хранилище Orca и выбор модели.
- Добавлена защищённая локальная панель с предварительным просмотром, явным согласием, применением, восстановлением и удалением ключа плагина.
- Реализованы семь адаптеров нативной конфигурации: Claude Code, Codex, OpenCode, Pi, oh-my-pi, Aider и Qwen Code. Модели Aider направляются через префикс `openai/` по документации агента.
- Добавлены резервные копии по файлам, права доступа POSIX и отказ от восстановления поверх последующих пользовательских изменений.
- Документированы ограничения протоколов, профилей, удалённых окружений и WSL, открытое хранение ключей в конфигурациях CLI и срок жизни worker. Публикация в marketplace и успешная генерация ответа агентом не заявлены.
