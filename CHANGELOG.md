# История изменений

## 1.0.1

- Ссылки на репозиторий и исходники приведены к `https://github.com/taranttoola-create/wikivibe-orca-plugin`. Основной адрес установки закреплён за тегом версии: `https://github.com/taranttoola-create/wikivibe-orca-plugin.git#v1.0.1`.
- README переписан как руководство: установка через Git URL и локальную папку, подключение, нативные пути и протоколы агентов, риски хранения ключей, восстановление и разбор ошибок. Сохранены ограничения совместимости и границы проведённых проверок.
- Название WikiVibe Gateway и описания плагина, панели и публикации согласованы. Доступность адаптера не выдаётся за обнаружение CLI; каталог моделей не выдаётся за подтверждение успешного запроса или универсальной совместимости.
- Удаление ключа названо по фактическому действию: команда «WikiVibe: Удалить сохранённый ключ» удаляет ключ из хранилища Orca, но не меняет конфигурации и не отключает сессии агентов.
- Инструкции упаковки и подготовки marketplace index используют версию `v1.0.1`. Документированы тег или полный 40-символьный SHA для Git URL; сокращённый SHA не рекомендуется.

## 1.0.0

- Создан самостоятельный плагин `wikivibe.gateway` для Orca plugin API 1. Поддержана обычная установка из локальной папки или Git-источника; отдельный helper не нужен.
- Добавлены регистрация по партнёрской ссылке, разрешённые адреса API/VAPI, проверка каталога до сохранения ключа в зашифрованном хранилище Orca и выбор модели.
- Добавлена защищённая локальная панель с предварительным просмотром, явным согласием, применением, восстановлением и удалением ключа плагина.
- Реализованы семь адаптеров нативной конфигурации: Claude Code, Codex, OpenCode, Pi, oh-my-pi, Aider и Qwen Code. Модели Aider направляются через префикс `openai/` по документации агента.
- Добавлены резервные копии по файлам, права доступа POSIX и отказ от восстановления поверх последующих пользовательских изменений.
- Документированы ограничения протоколов, профилей, удалённых окружений и WSL, открытое хранение ключей в конфигурациях CLI и срок жизни worker. Публикация в marketplace и успешная генерация ответа агентом не заявлены.
